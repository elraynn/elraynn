# Hi, I'm Rayhan

Web developer in North Jakarta. At work I build and maintain ERP systems for
Indonesian companies: accounting, inventory, payroll and tax invoicing. Mostly
PHP (CodeIgniter and Laravel), MySQL and jQuery, plus some Flutter.

These libraries came out of problems I kept running into at work:

- [coretax-faktur](https://github.com/elraynn/coretax-faktur): generate Coretax
  e-Faktur XML from your own invoice data, with the VAT math and validation
- [twins](https://github.com/elraynn/twins): find code that was copied between
  projects and see how much each copy has changed
- [auto-number](https://github.com/elraynn/auto-number): sequential document
  numbers without the SELECT MAX()+1 race condition
- [approval-flow](https://github.com/elraynn/approval-flow): role-gated state
  machine for multi-step approvals
- [table-export](https://github.com/elraynn/table-export): export arrays or
  query results to Excel or PDF with one API
- [jquery-lookup-modal](https://github.com/elraynn/jquery-lookup-modal):
  keyboard-driven picker modal for Bootstrap 4 + DataTables

More about me at [elrayn.com](https://elrayn.com).
